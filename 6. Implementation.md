## 8. Dependencies & Risks

| Dependency | Risk | Mitigation |
|-----------|------|------------|
| Fivetran connector availability | Medium | Prioritize natively supported connectors; build fallback importers |
| Gemini 2.5 Pro API availability | Low | Have fallback model (Gemini 1.5 Pro); abstract model layer |
| Plaid API for subscription cancellation | High | Implement email-based cancellation as fallback |
| Fivetran sync latency > 15 min | Medium | Implement polling with shorter intervals for critical connectors |
| Arize Phoenix self-improvement accuracy | Medium | Human-in-the-loop review of auto-generated improvements |
| Google Cloud Run cold starts | Low | Configure min instances, warm-up requests |
| MongoDB Atlas connection pooling | Low | Monitor connection pool, auto-scale with Cloud Run |
